Android 16 以降に対応する、端末内で管理する個人用ポッドキャストアプリです。

- ニュース・技術・英語学習など、名前を付けた複数の再生キューを作成・並べ替え・連続再生
- 同じ回を複数キューに登録でき、聴き終えた回はすべてのキューから削除（音声と履歴は保持）
- 番組ごとの新着自動追加、含む語・除外語、どれか／すべて一致の条件
- 番組単位・キュールール単位の自動ダウンロード、約1時間ごとのバックグラウンド新着確認
- 従来の購読・履歴・保存済み音声を保持して更新

Apple Podcasts 検索、主要プラットフォームの番組URL・RSS/Atom、オフライン再生、再生位置復元、0.5〜3倍速にも対応します。アカウント・レコメンド・クラウド同期はありません。
