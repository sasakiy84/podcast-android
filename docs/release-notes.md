キューの整理とエピソード一覧を改善しました。

- キューの自動送りで、番組ごとの冒頭スキップが効かないことがある問題を修正
- キュー画面に「キューとローカルデータを削除」を追加。確認後に表示中のキューを空にし、その中の保存音声とダウンロード予約を削除
- キュー名・自動追加設定・履歴・他のキューへの所属は保持
- エピソード一覧の初期フィルターを「ダウンロード」に変更
- 再生パネルの表示・非表示が変わっても、フィルターや選択中のキューを保持
- READMEに最新画面のスクリーンショットと機能紹介を追加

通常の途中再開、チャプター指定、スキップ後の手動シークは維持します。保存音声は全キューで共有しているため、一括削除した音声は他のキューからもオフライン再生できなくなります。

端末内の購読・キュー・履歴を引き継いで更新できます。
