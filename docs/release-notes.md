Android 16 以降向けの個人用ポッドキャストアプリです。

- ミニプレーヤーと再生詳細を一つの常設 Material シートに統合。上へ開く途中も下へ閉じる途中も指に追従
- 再生中・詳細・チャプターを左右スワイプとタップで切り替えるページャーに変更
- 再生画面のキュー追加に追加済みアイコンと結果メッセージを表示。メッセージが再生画面の裏に隠れる問題を修正
- 更新間隔のボタンに余白を追加し、狭い画面では折り返して表示
- 番組の長い説明文を5行に折りたたみ、タップで全文を展開。コピーとリンクに対応
- 混在するエピソード一覧に番組画像を表示し、番組詳細の一覧では省略。操作ボタンをまとめてタイトルの幅を確保
- 速度・購読元・キュー編集・確認シートは閉じるアニメーションが終わってから画面を取り除くよう統一

実機での操作確認は未実施です。

134件の自動テスト、Lint、APKビルドを通過し、明暗・文字拡大を含む104枚の画面画像を確認しています。

再生シートの開閉に合わせてステータスバー・ナビゲーションバーのアイコンの明暗を切り替えます。
