番組の定期更新とダウンロードの待機中に、端末で行う処理を減らしました。

- バックグラウンド更新の既定を6時間に変更し、オフも選べるようにしました。選択済みの間隔は引き継ぎます。アプリを開くと、前回の確認から時間が経った番組を更新します。
- 画面を閉じると、保存の進捗や再生位置を表示するための定期確認を止めます。
- 自動ダウンロードにWi-Fi、充電、空き容量の条件と番組ごとの新着上限を追加しました。待機理由を表示し、手動での開始や失敗した回の再試行ができます。
- ダウンロード一覧から再生すると、その回が入っているキュー、番組に設定したキュー、既定キューの順に再生先を選びます。
- モバイル回線で未保存の音声を取得する前に確認します。設定でオフにできます。
- 番組詳細から、その番組の回をすべてのキューから外して保存音声を削除できます。キュー単位の削除ボタンも詳細画面の上部に移しました。
