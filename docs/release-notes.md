Android 16 以降向けの個人用ポッドキャストアプリです。今回から通常リリースとして公開します。

- 挙動とデザインを維持して、再生コマンド、画面状態への設定反映、エピソード詳細シート、HTTP通信を分離
- 全テストを監査し、重複・自己検証・標準ライブラリの再確認を削除・統合
- 過去のDB移行テストを独立した旧版SQLへ置き換え、再生操作と停止中シークは実ExoPlayerでも検証
- 全画面撮影を必要なときだけ実行する形に分離し、白抜けパネルの全初期フレームの描画検査は保持

監査の対象・判断・代替保証は [docs/test-audit.md](https://github.com/sasakiy84/podcast-android/blob/v0.8.0/docs/test-audit.md) に記載しています。

118件の回帰テスト、Lint、APKビルドを通過しました。明暗・文字拡大を含む110枚の画面画像も変更前と画素一致しています。画面比較はRobolectricの描画で行い、実機での確認は未実施です。
