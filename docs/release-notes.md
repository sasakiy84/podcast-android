Android 16 以降向けの個人用ポッドキャストアプリです。

- 再生パネルがないときの通知下の余白を修正。表示中の下部バーの実測高さに合わせて配置
- エピソード詳細と再生画面の詳細タブに番組へのリンクを追加。戻ると元の一覧位置を復元
- キュー内の重複した追加ボタンを削除。各行は再生を主操作にし、ダウンロードは情報行へ配置
- キューの名前変更・自動追加ルール・削除を一つのメニューへ集約し、再生ボタンと件数の配置を簡素化
- デフォルトキューへの追加はスワイプ・エピソード詳細・再生画面から利用可能
