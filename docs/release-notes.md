Android 16 以降向けの個人用ポッドキャストアプリです。

- ETag・Last-Modifiedを使う条件付きRSS取得で、未変更フィードの本文取得を省略
- 保存済みの全エピソードのタイトル・説明を検索し、未再生・保存・お気に入り・履歴で絞り込み
- 再生済みへの変更・キューから外す操作を取り消し、キューをドラッグで並べ替え
- 設定の「ストレージと更新」で容量・最終確認・取得失敗・Wi-Fi待ちを確認し、個別に再試行
- タイトル・エピソードURL・本文のコピーと他アプリへの共有。任意で再生位置と秒数を追加
- 古いDBの購読・進捗・キュー等を保持して移行

仕様と検証は [docs/library-operations.md](https://github.com/sasakiy84/podcast-android/blob/v0.9.0/docs/library-operations.md) にまとめています。以前提供された123番組・36,486エピソードでも登録・更新・一覧外の全文検索を確認しました。個人データは含めていません。

画面と操作の検証はRobolectricです。実機での確認は未実施です。
