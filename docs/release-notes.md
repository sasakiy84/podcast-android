Android 16 以降向けの個人用ポッドキャストアプリです。

- 再生パネルの初期高さを dp とシステム余白から決定し、描画後の自己計測でシートの位置がずれる構造を修正
- レイアウトでアンカーが更新されてから移動し、既に折りたたまれている場合は不要な移動を起動しない
- 折りたたみ時はパネルを不透明で保持し、1080×2340相当・密度3・システムバーありの初期各フレームで位置と描画ピクセルを検証
- エピソード一覧とキュー内の各行は、再生ボタンだけを表示
- 保存・キュー追加・並べ替え・コピーなどは詳細画面、スワイプ、長押しメニューから操作可能

実機での確認は未実施です。

145件の自動テスト、Lint、APK ビルドを通過しています。追加の描画検証では、明暗テーマと初期フレームで再生ボタンの描画も確認しています。
