Android 16 以降向けの個人用ポッドキャストアプリです。

- 再生画面を標準の ModalBottomSheet に変更。指に追従するドラッグ、速度に応じた開閉、閉じるボタン・戻る操作のアニメーションに対応
- 戻る操作を整理し、番組詳細・検索・キューから上位画面へ戻る構成に変更。設定は独立した SettingsActivity
- OPML のインポート・エクスポートと全体の再生速度を設定画面へ移動
- 起動時の全番組更新を廃止。1・3・6・12・24時間の更新間隔と手動更新に対応
- Wi-Fi 限定ダウンロード。設定変更を待機中・実行中のリクエストにも反映し、保存完了済みの音声は保持
- 番組ページからキューへの自動追加条件を設定。キュー画面での番組選択を廃止
- デフォルトキューへのワンタップ追加と、行全体で操作できるキュー選択
- 再生画面に現在のチャプター・前後のチャプター移動、エピソードの前・次ボタンを追加
- 番組一覧の追加ボタンを削除。番組登録は検索タブに集約

再生完了時の保存音声の自動削除、履歴・お気に入りの保持、既存の番組別設定を引き継ぎます。実機での操作確認は未実施です。
