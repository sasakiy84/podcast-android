Android 16 以降向けの個人用ポッドキャストアプリです。

- 横スワイプでキュー追加・再生済み・お気に入り・保存。キュー内ではそのキューから外す操作
- ミニプレーヤーの上スワイプ、プレーヤーヘッダーの下スワイプ
- サムネのメモリ／ディスクキャッシュ、番組の新着順・タイトル順切り替え
- 全体と番組個別の再生速度、お気に入り一覧、購読元URL・Webサイト表示
- 番組ページから戻った際のスクロール位置、タブごとの検索・絞り込みを保持
- 大量OPML登録時の一括読込を分割し、大きなRSSのストリーム解析と更新の同時接続数制限に対応

添付の123番組・36,486エピソードで、256MiBのテストヒープ制限下で取り込み・更新を検証しました。既存の購読・キュー・再生履歴・保存済み音声を引き継ぎます。
