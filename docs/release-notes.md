Android 16 以降向けの個人用ポッドキャストアプリです。

- 再生画面のアートワークを下へスワイプして閉じる操作、一覧を引っ張って更新する操作
- 停止中・復元直後の再生位置変更を修正。再生を開始せずにシーク可能
- 説明文の改行・段落・箇条書き・URLリンク、タイトルや説明・音声URLのコピー
- 再生済みの表示を薄くし、視聴履歴を追加
- 再生完了時に保存音声を自動削除（末尾スキップも対象）。履歴・お気に入りは保持
- エピソード一覧のサムネイルを外し、直接ダウンロードできるボタンを追加。ミニプレーヤーの戻る操作に15秒を表示
- Podlove / Podcasting 2.0 JSON チャプターの表示と再生位置への移動
- 番組別の新着通知、最初・最後をスキップする秒数設定
- 画面・再生操作・キュー同期・ダウンロード処理を分離し、既存の購読・キュー・音声を保持したデータ移行に対応

添付OPMLの123番組・36,486エピソードを256MiBのテストヒープ制限で再検証し、rebuild.fm の実RSSでもチャプターと説明リンクを確認しました。116件の自動テストと Lint を通過しています。画面画像は明暗・文字拡大を含む98枚です。実機の操作・音声出力確認は未実施です。
