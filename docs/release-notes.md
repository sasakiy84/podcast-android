キューの連続再生とダウンロードの扱いを改善しました。

- キューを聴き終えたら既定キューへ移り、既定キューも空・削除済みなら未再生の回がある別のキューを再生
- すべてのキューが空なら停止し、再生済みの回を繰り返さないように対応
- ダウンロード一覧を公開日順から、新しく取得を開始した順に変更。検索結果にも適用
- お気に入りの保存音声は、再生完了・末尾スキップ後も端末に保持

一時停止中・起動時の復元・キューの音声をまとめて削除した直後には、自動再生を開始しません。移動先の番組ごとの冒頭スキップと途中再開位置にも対応しています。

端末内の購読・キュー・履歴・保存音声を引き継いで更新できます。
