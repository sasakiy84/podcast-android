エピソード間の音量差を抑える「音量をそろえる」を追加しました。

- 設定から「標準」「大きめ」を選択。初期設定はオン・標準
- 再生中に音量を測定して補正し、急に大きくなる音にはピーク制限を適用
- ダウンロード済み音声を端末内で事前解析し、解析済みなら再生開始時から補正
- 既存の保存音声もバックグラウンド解析の対象。解析できない場合は再生中の補正を使用
- 倍速再生やキューの自動送りにも対応

元の音声ファイルと端末の音量設定は変更せず、音声を外部へ送信しません。追加ライブラリは使用していません。

YouTubeなど他のアプリとの聴感差を小さくするための機能ですが、すべての音源・出力機器で同じ大きさになることを保証するものではありません。端末内の購読・キュー・履歴を引き継いで更新できます。
